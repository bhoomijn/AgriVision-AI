# Demo instructions

This file explains how to add a demo GIF and what the demo should show.

Place a demo GIF at `docs/demo.gif` (recommended size: 600x340, under 3MB). The demo should show:

1. Quick app start (show terminal commands to run the app)
2. Uploading a sample leaf image
3. The model output and confidence score

If you want, I can create a placeholder GIF and add it to the repo — reply `add demo`.
