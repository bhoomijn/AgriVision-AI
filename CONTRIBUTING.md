# Contributing

Thanks for your interest in improving AgriVision-AI! A few guidelines to keep contributions smooth:

- Fork the repo and open a pull request against `main`.
- Keep changes small and focused (one feature / fix per PR).
- If you add dependencies, update `requirements.txt` and explain why in the PR.
- Add tests where applicable in a `tests/` folder.
- For major changes, open an issue first to discuss the approach.
