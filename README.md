# 🚀 Overview

**AgriVision AI** is an AI-powered smart agriculture platform designed to help farmers detect crop diseases at an early stage using Artificial Intelligence and Computer Vision.

The platform enables farmers to upload crop leaf images, analyze plant health using a Vision Transformer (ViT) model, identify possible diseases, generate confidence-based predictions, and receive treatment recommendations. By making advanced AI technology simple and accessible, AgriVision AI supports faster decision-making, reduces crop losses, and promotes smarter farming practices across India.

---

# 🎯 Problem Statement

Agriculture is one of the strongest pillars of India's economy and supports the livelihood of millions of farming families. However, crop diseases are often detected only after significant damage has occurred due to limited access to agricultural experts, lack of timely diagnosis, and dependence on manual inspection.

Late disease detection leads to reduced productivity, increased farming costs, and financial losses. Farmers need an affordable, intelligent, and accessible solution that provides instant crop health analysis and actionable recommendations.

---

# 💡 Our Solution

AgriVision AI combines Artificial Intelligence and Computer Vision to provide instant crop disease detection.

Using a simple smartphone interface, farmers can:

* 📷 Upload a crop leaf image
* 🤖 Receive AI-powered disease detection
* 📊 View confidence-based predictions
* 🌿 Get treatment recommendations
* 🌦 Make informed farming decisions

The platform transforms complex AI into a practical solution that farmers can use easily without requiring technical expertise.

# 🧠 Artificial Intelligence Model

AgriVision AI uses a Vision Transformer (ViT) image classification model for crop disease detection.

| Component    | Details                             |
| ------------ | ----------------------------------- |
| Model        | wambugu71/crop_leaf_diseases_vit    |
| Architecture | Vision Transformer (ViT)            |
| Framework    | Hugging Face Transformers + PyTorch |
| Task         | Crop Leaf Disease Classification    |

### Supported Crops

* 🌾 Wheat
* 🌽 Corn
* 🥔 Potato
* 🍚 Rice
